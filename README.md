# Pure Harvest 3D Storefront

A premium React + Vite concept for a new Pure Harvest Pakistani food ecommerce experience.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Current scope

- Interactive Three.js / React Three Fiber hero
- Premium natural green / cream / earth palette
- Product search and category browsing
- Quick-view product modal
- Product variants for Chakki Flour and Desi Ghee
- Working client-side cart interaction
- Responsive mobile navigation and layouts
- No fabricated reviews, certifications, awards, statistics, or company claims

## Production integration still required

Connect the real Pure Harvest product prices, images, Firebase/Firestore data, authentication, checkout/order workflow, contact information, and protected admin functionality after inspecting the existing store schema. Do not expose private credentials or weaken database rules.
